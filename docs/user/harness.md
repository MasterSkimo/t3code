# Harness learning

Harness learning looks for reusable practices in completed work and prepares recommendations for review. Find it under **Settings → Harness learning**.

Enable learning to allow analysis. Automatic learning checks eligible completed work in the background; **Learn now** starts an analysis immediately. You can choose an analysis model, daily budget, and minimum confidence.

Review each proposal's evidence and content before approving or rejecting it. Approved proposals can be exported as Markdown for manual use. Approval does not change provider configuration. Previously applied proposals remain in history and can be rolled back while their saved rollback data is available.

After implementing an approved proposal outside T3 Code, mark it implemented to record your confirmation and use that timestamp for an observed outcomes snapshot. This records your report; it does not verify the change.
