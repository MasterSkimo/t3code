# Harness learning

Harness learning looks for reusable practices in completed work and prepares skill changes for review. You can find it under **Settings → Harness learning**.

Turn on **Enable learning** to allow analysis. **Learn automatically** analyzes eligible work in the background; **Learn now** starts an analysis immediately. Choose an analysis model or leave the model fields blank to use the server's configured text-generation model. The daily analysis budget limits how many analyses run, and the minimum confidence filters out lower-confidence suggestions. Save settings to apply them.

Harness records suggestions as proposals. Review the supporting evidence and proposed content, then approve or reject each proposal. Approval records your decision; choose **Apply** on an approved proposal to write the skill. Created skills appear in the inventory. Harness marks which skills it manages, and will not overwrite an unmanaged skill. You can roll back an applied change from its proposal while Harness still has the saved rollback data.

The activity and history sections show proposal counts and recorded decisions. The skill inventory and proposals belong to the selected environment. Global skills are shared from that server's user skill directory; project skills live with their project.
