# Native Plotline DAGs

Ask an agent in a T3 thread to create or update a DAG, and it can use T3's native Plotline tools to save it in the current project. Open the returned DAG link to view it; the DAG page receives updates from the server. Ask explicitly for Markdown or Mermaid if you want a file or text instead.

Changes through the agent tools are unavailable in Plan mode. If the provider session does not expose T3's MCP tools, the agent cannot create a native DAG through them.
